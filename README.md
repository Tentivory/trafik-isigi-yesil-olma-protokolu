# Trafik Işığı Yeşil Olma Protokolü

## Resmi Belge - Kayyum Onaylı

Bu repository, insanlığın en büyük sorunlarından biri olan **trafik ışığı bekleme** olayını bilimsel, resmi ve abartılı bir şekilde çözmek için yaratılmıştır.

### Neden Var?

Çünkü yeşil ışık gelene kadar bekliyorsunuz. Ama nasıl bekleyeceksiniz? Protokol olmadan bekleyemezsiniz. Bu, modern toplumun temelidir.

### Nasıl Çalışır?

```bash
python trafik_protokolu.py
```

Program başlar. Işık kırmızıdır. Beklersiniz. Bazen çok beklersiniz. Bazen yeşil gelir, bazen gelmez. Protokol her zaman doğrudur.

### Özellikler

- %100 resmi dil
- Gerçekten bekler (time.sleep kullanır, sahte değil)
- Rastgele gecikmeler (trafik ışıkları böyle çalışır)
- Felsefi sorgulamalar içerir
- KeyboardInterrupt ile durdurulabilir (bu da bir karardır)

### Uyarı

Bu protokol gerçek trafik ışıklarında kullanılamaz. Kullanırsanız sorumluluk size aittir. Yeşil ışık gelmeyebilir. Bu normaldir.
